# City Builder — Telegram Mini App

Текстовый идле-симулятор города: начинаешь с посёлка и строишь его до мегаполиса.

</div>

Это отдельный самостоятельный проект внутри репозитория (не связан с KinoBot):
свой бот (Aiogram3), свой веб-сервер (FastAPI) и свой Mini App (обычные HTML/CSS/JS
без сборки), который открывается кнопкой WebApp в Telegram.

Никаких картинок — весь геймплей завязан на цифрах (население, деньги, счастье)
и текстовых карточках построек.

## Геймплей

1. При первом запуске ты придумываешь название своего города. Начинаешь как
   «Посёлок».
2. Строишь здания: жилые дома (население), фермы/заводы/торговые центры/небоскрёбы
   (доход в секунду), школы/больницы/парки/университеты (счастье), дороги/метро
   (инфраструктура).
3. Население растёт само по себе в сторону жилой вместимости — скорость роста
   зависит от уровня счастья. Слишком низкое счастье (переполненный, несчастный
   город) может привести к оттоку населения.
4. Чем больше населения — тем выше статус города: Посёлок → Деревня → Посёлок
   городского типа → Городок → Город → Крупный город → Мегаполис.
5. Прогресс считается и оффлайн: при следующем заходе игра досчитает, что
   произошло за время отсутствия (не более 8 часов накопления за раз).

## Стек

- Python 3.10+, FastAPI + Jinja2 — веб-сервер и API мини-аппа
- Aiogram3 — бот, который открывает Mini App кнопкой
- SQLite — хранение прогресса игроков (по `telegram_id`)
- Ванильные HTML/CSS/JS + официальный Telegram Web App SDK — фронтенд, без сборки

## Быстрый старт

1) Создай бота через [@BotFather](https://t.me/BotFather), получи `BOT_TOKEN`.

2) Установи зависимости:

```bash
cd citybuilder
python -m pip install --upgrade pip
pip install -r requirements.txt
```

3) Скопируй `.env.example` в `.env` и заполни `BOT_TOKEN`. `WEBAPP_URL` должен
   указывать на публичный HTTPS-адрес (Telegram не откроет Mini App по http) —
   для локальной разработки можно прокинуть порт наружу через ngrok/cloudflared
   и указать полученный https-адрес.

```bash
cp .env.example .env
```

4) Запусти:

```bash
python main.py
# Веб-часть поднимется на http://HOST:PORT (по умолчанию :5566)
```

5) В Telegram отправь боту `/start` и нажми кнопку «Строить город».

### Локальная проверка без Telegram

Если выставить `TESTING=true` в `.env`, эндпоинты `/api/game/*` принимают
`?dev_user_id=<любое число>` вместо валидированного заголовка
`X-Telegram-Init-Data` — удобно для локальной отладки без реального бота:

```bash
curl "http://localhost:5566/api/game/state?dev_user_id=1"
```

## Тесты

Игровая логика (`app/game/logic.py`) не зависит от FastAPI/Aiogram/БД и
покрыта тестами:

```bash
cd citybuilder
pip install pytest
python -m pytest tests/ -q
```
